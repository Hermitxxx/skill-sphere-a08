## What you can do
- Browse tech-focused courses in a clean catalog experience  
- Discover skills by category / topics (designed for quick decision-making)  
- Learn with a UI built for clarity and speed  

---

## Product highlights (startup vibe)
- **Conversion-friendly UI:** sections, hierarchy, clarity  
- **Responsive by default:** works great on mobile and desktop  
- **Modern styling:** consistent spacing, sharp layout, readable typography

## Getting started (local)
```bash
# 1) clone
git clone https://github.com/Hermitxxx/skill-sphere-a08.git

# 2) go to project
cd skill-sphere-a08

# 3) install (if package.json exists)
npm install

# 4) run
npm run dev
```

> If your project uses a different command (e.g. `npm start`), swap it in.
